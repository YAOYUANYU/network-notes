# network-notes

网络工程专业学习笔记与实践仓库。

## 仓库结构

| 目录/文件 | 用途 |
|---|---|
| `notes/` | 课程笔记，按知识模块拆分 |
| `labs/` | 实验记录、抓包文件、拓扑图 |
| `projects/` | 课程设计、小项目源码 |
| `resources.md` | 收藏的优质学习资源 |

## 使用说明

1. 每学完一个知识点，写进对应的 `notes/*.md`
2. 做完实验，把拓扑、抓包、结论记录到 `labs/`
3. 提交规范：`git commit -m "笔记: 补充 TCP 三次握手"`
