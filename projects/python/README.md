# Python 学习计划（项目驱动）

> 目标：每完成一个项目，就掌握一批知识点。全部做完，你就能自己写网络工程相关的脚本。

## 怎么用这个目录

每个项目一个文件夹，里面通常有两个文件：

- `xxx.py` —— 代码（**建议你照着敲一遍，不要只复制**）
- `README.md` —— 本项目知识点 + 练习任务

做完一个项目，就把下面表格里的「状态」改成「已完成」。
