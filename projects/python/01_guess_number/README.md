# 项目 1：猜数字游戏

## 你会学到

| 知识点 | 说明 |
|---|---|
| 变量 | 给数据起个名字，比如 `secret`、`count` |
| `import` | 导入 Python 自带的工具包（这里是 `random`） |
| `input()` | 接收键盘输入，拿到的是**文字** |
| `int()` | 把文字转成整数 |
| `if / elif / else` | 做判断，走不同的分支 |
| `while` | 重复执行一段代码 |
| `break` | 跳出循环 |
| `print()` | 在屏幕上输出内容 |

## 怎么运行

1. 打开这个文件夹
2. 在地址栏输入 `cmd` 回车（或在文件夹空白处右键 → 在终端中打开）
3. 输入下面的命令并回车：

```bash
python guess_number.py
```

然后按提示输入数字，就能玩了。

## 练习任务

做完基础版后，试着改代码完成下面几个挑战：

1. **改范围**：把 1~100 改成 1~1000
2. **限次数**：最多只能猜 10 次，超过就提示「失败，答案是 XX」
3. **防崩溃**：如果输入的不是数字（比如输入了 abc），程序不要报错崩溃

> 提示：挑战 2 需要用 `if count >= 10` 判断；挑战 3 需要用到 `try / except`（先不用急，做不出来我们再一起看）。
