## 核心概念

### TCP 三次握手

1. 客户端 → 服务端：SYN
2. 服务端 → 客户端：SYN + ACK
3. 客户端 → 服务端：ACK

### 四次挥手

1. 客户端 → 服务端：FIN
2. 服务端 → 客户端：ACK
3. 服务端 → 客户端：FIN
4. 客户端 → 服务端：ACK

### TCP vs UDP

| 特性 | TCP | UDP |
|---|---|---|
| 连接 | 面向连接 | 无连接 |
| 可靠性 | 可靠、有序 | 不保证 |
| 速度 | 较慢 | 较快 |
| 典型场景 | HTTP、FTP | DNS、视频流、游戏 |
